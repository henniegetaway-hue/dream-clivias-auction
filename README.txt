DREAM CLIVIAS AUCTION — TEST PROTOTYPE

1. Open index.html in Chrome or Edge.
2. ADMIN test password: 1234
3. In Admin:
   - Set auction title, default bid increment, delivery fee, bank details.
   - Add as many lots/rows as needed.
   - Upload a FLOWER photo and ACTUAL PLANT photo for each lot.
4. Register test bidders under Register.
5. Select a bidder and go to Live Auction to place bids.
6. The system automatically validates the minimum next bid and keeps full bid history.
7. In Admin, press CLOSE AUCTION + CREATE INVOICES.
8. Invoices are grouped by winner. Each invoice includes winning lots and actual plant pictures.
9. Use SEND / OPEN WHATSAPP to open a pre-filled winner message to that buyer.
10. Use PRINT / SAVE INVOICE PDF to print or save the invoice as PDF.

IMPORTANT TEST LIMITATION
This version runs entirely on one device/browser and stores data in browser Local Storage.
Fully automatic WhatsApp sending (without clicking) requires the live hosted version to connect to the official WhatsApp Business Cloud API. The prototype includes an AUTO-SEND TEST button that simulates this workflow.

BACKUP
Use EXPORT BACKUP in Admin to save all auction data as JSON. IMPORT BACKUP restores it.
